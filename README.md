# agent-kit

A Claude Code plugin marketplace with the shared coding-agent kit for my projects: planner, implementer, verifier, reviewer, deep reviewer and review handler agents, plus skills such as carrying an improvement upstream to a project template. Projects generated from [house-template-base](https://github.com/olaheavy-dev/house-template-base) turn it on in `.claude/settings.json`.

Work in progress: the kit arrives through reviewed pull requests.
